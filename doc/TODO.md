# Vein Miner Mod — Suggested Features & Roadmap

## QoL Features
- [ ] HUD Feedback
  - Show current mining mode (`small`/`large`).
  - Show dig queue status / scan range / light status.
  - Show layer info and light gaps visually.
- [ ] Sneak-tap toggle
  - Allow players to toggle vein mining mode by sneak + dig (instead of chat command).

## Enhancements
- [ ] Visual beam/indicator to show dig area bounds.
- [ ] Configurable max distance from player before mining is canceled.
- [ ] Toggle for auto-light placement.
- [ ] Cooldown between mining actions.
- [ ] Better stuck detection (e.g., stuck in sticky nodes).
- [ ] Node filters in HUD or config (e.g., ignore dirt).
- [ ] Sound feedback on mine start, queue empty, etc.

## Dev/Debug Tools
- [ ] Command to print/debug queue contents.
- [ ] Command to simulate light scan without digging.

## Compatibility / Integration
- [ ] Support for more modded nodes (stone with crystal, etc.).
- [ ] Autodetect diggable nodes based on tool capabilities.
- [ ] Mesecon signal trigger support.
